# Smart Notepad Web Application

A responsive and feature-rich Smart Notepad Web Application built using HTML, CSS, and JavaScript. This application allows users to create, edit, save, and manage notes directly in their browser while providing multimedia capabilities such as image capture and voice recording.

## Features

* Create, edit, and manage text notes
* Save and delete notes efficiently
* Capture images using the device camera
* Record and save voice notes
* Customize font size for better readability
* Responsive and user-friendly interface
* Works directly in the browser without additional software

## Technologies Used

* HTML5
* CSS3
* JavaScript
* MediaDevices API (Camera Access)
* Web Audio API
